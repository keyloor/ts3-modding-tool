INSTALL (with Toy Story 3 Mod Loader by keyloor, free)
  1. Download Toy Story 3 Mod Loader from the Files tab:
     https://www.nexusmods.com/toystory3completeedition/mods/30
     Extract its zip outside the game folder and open "Toy Story 3 Mod Loader.exe".
  2. Close the game.
  3. Drag this mod's zip onto the Mod Loader window (or press "Install mod..." and pick
     it). Check the list of files it changes and press "Install this mod".
  If you already have Modding Tool, you can also use Manage mods there.

UNINSTALL
  Open Mod Loader, select this mod and press "Remove mod". Remaining mods are rebuilt and files no longer
  changed by any mod are restored from the original backups.

OTHER CHARACTER MODS
  Use Mod priorities to choose which mod wins when two mods change the same ZIP member. Higher priority wins;
  different members combine. An OCT is replaced as a whole, without per-texture merging.
