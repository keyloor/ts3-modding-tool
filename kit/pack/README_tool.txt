@@WHAT@@

INSTALL (needs TS3 Modding Tool by keyloor, free)
  1. Close the game.
  2. Open TS3 Modding Tool > Manage mods, and drag this zip onto the window (or press "Install mod..." and pick
     it). Check the list of files it changes and press "Install this mod".
  Without the window: "TS3 Modding CLI.exe" mods install "<this zip>" --game "<game folder>"

UNINSTALL
  TS3 Modding Tool > Manage mods > select it > "Remove mod". The game's files go back to how they were.

OTHER CHARACTER MODS
  Mods that replace the same character change the same archive: the tool tells you if another installed mod
  already changes it.

WHAT IT CHANGES
  Only @@ARCHIVE_WIN@@ inside the game folder. This pack holds no programs or scripts: only this mod's changes
  (patches/) and mod.json, which says what they are.
