INSTALL
  Close the game before installing or removing this mod.
  You can also install this pack with Toy Story 3 Mod Loader, available from the Files tab:
  https://www.nexusmods.com/toystory3completeedition/mods/30
  Drag this mod's zip onto its window and review the installation. Remove it with the same manager.
  Choose one installation method. Before switching methods, uninstall with the one you used.

  To use this pack's standalone installer instead (no Mod Loader required):
  1. Close the game and extract this zip (right-click it > Extract All).
  2. Double-click "Install @@NAME@@.bat" and press Enter when it shows your game folder.
  If Windows warns about the file, choose "More info" > "Run anyway".

UNINSTALL (standalone installer)
  Double-click "Uninstall @@NAME@@.bat". It puts the game's archive back from its backup. If another mod changed it
  afterwards, only this mod's files are taken out, so the other mod's changes stay.

OTHER CHARACTER MODS
  With the standalone installer, mods that replace the same character change the same archive: you see the one
  installed last. Uninstall them in reverse order. With Mod Loader, use Mod priorities instead.

WHAT THE STANDALONE INSTALLER CHANGES
  Only @@ARCHIVE_WIN@@ inside the game folder, plus a "@@NAME@@ backup" folder there and the temporary log below.
  No downloads or Windows settings changes. @@SCRIPT@@ does the work and is plain text: open it in
  Notepad to read it. Log: %TEMP%\@@NAME@@ Setup.log
