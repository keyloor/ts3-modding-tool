# Toy Story 3 Mod Loader

by keyloor — for Toy Story 3 Complete Edition on PC (Steam).

## Español

Abre `Toy Story 3 Mod Loader.exe`. La aplicación busca el juego en Steam; si no lo encuentra,
elige su carpeta con «Elegir carpeta». No necesitas Python.

Para instalar, pulsa «Instalar mod…» o arrastra el ZIP del mod a la ventana. También puedes
elegir «Más opciones → Instalar desde carpeta». Revisa su nombre, autor y archivos antes
de pulsar «Instalar este mod». Cierra el juego antes de instalar o quitar mods.

Para actualizar un mod, elige el ZIP o carpeta de la nueva versión. Si conserva el mismo ID,
la revisión muestra ambas versiones y «Reemplazar este mod». También sirve para probar un pack
regenerado con la misma versión. Se conservan los respaldos de la primera instalación, y los archivos
que el nuevo pack deja de cambiar vuelven a su estado anterior. Si falla, se recupera la versión instalada.
Las dependencias incompatibles, archivos cambiados fuera del gestor y copias dañadas bloquean el reemplazo.

Selecciona un mod para ver su descripción. «Quitar mod» restaura los archivos anteriores;
«Verificar archivos» comprueba su instalación y las copias. Si existe una actualización,
puedes abrir su página para descargarla. El Loader no descarga ni ejecuta instaladores.

La verificación muestra por archivo su estado, la copia original y los datos guardados de los mods que comparten
ese destino. Selecciona una fila para ver el motivo de un problema. No repara ni sobrescribe archivos; los hashes
y el JSON quedan en «Detalles técnicos». «Más → Ver resultado» abre la última comprobación de esta sesión. Recargar la
lista la descarta: vuelve a verificar después de cambiar archivos o prioridades. Un aviso «Revisar archivos» tiene
preferencia sobre una actualización disponible. La búsqueda admite nombre, autor, descripción e identificador,
y el contador indica cuántos mods coinciden. Si hay una operación interrumpida, la lista pide recuperarla.
El panel separa Descripción y Archivos que cambia en pestañas con desplazamiento. «Más» también da acceso a
su actualización, cuando existe; verificar y quitar permanecen a la vista sin ocultar los archivos a tamaño mínimo.

Toy Story 3 Mod Loader y Toy Story 3 Modding Tool comparten el mismo registro y las mismas
copias de seguridad dentro de la carpeta del juego. Los mods que ya instalaste con el
gestor de la Modding Tool aparecen aquí. Los de otros instaladores no se registran automáticamente.
«Prioridades de mods» permite ordenar las capas: menor prioridad arriba, mayor abajo. Los nuevos mods
van al final y las actualizaciones conservan su posición. Revisa el orden antes de aplicar; el último gana
si dos mods cambian la misma entrada del ZIP o el mismo archivo completo. Las entradas diferentes se combinan.
Un OCT coincidente se reemplaza completo: sus texturas individuales no se mezclan. Quitar una capa conserva
las demás; quitar la última restaura la copia original. El gestor guarda lo necesario sin depender del ZIP descargado.
Usa versiones actuales de ambas aplicaciones con los registros de capas; no los edites manualmente.

Si una operación se interrumpió, usa «Recuperar cambios». No borres manualmente el registro
ni las copias. Si un archivo cambió fuera del gestor, se conserva para evitar perderlo.

Para crear personajes, explorar niveles o editar texturas, usa la descarga separada
**Toy Story 3 Modding Tool**. El Loader está pensado para jugadores y contiene solo el gestor.

## English

Open `Toy Story 3 Mod Loader.exe`. It finds the game in Steam; otherwise choose its folder.
Install a mod ZIP with Install mod or by dropping it onto the window. Folders are accepted
through More options. Review the package before installing. Close the game for changes.

Choose a newer or rebuilt package with the same ID to replace an installed mod. The review shows both
versions and a Replace this mod button. Original backups are preserved, retired targets are restored,
and an interrupted replacement recovers the previously installed version. Incompatible dependents,
external changes and damaged backups block replacement. Downloads remain manual.

Select a mod to remove it, verify its files/backups or view its update page. The Loader and
Modding Tool share the same registry and backups, so managed mods appear in both. Mods
installed by other installers are not automatically tracked. Mod priorities orders all layers from lowest
to highest; last wins on matching ZIP members/whole files. Distinct patched members combine; an OCT is a
whole member, without per-texture merging. Updates keep position; removing a layer rebuilds the rest from
stored snapshots. Original backups remain. Use current versions of both apps for layered registries.
External edits, declared conflicts and broken dependencies are refused. Use Recover changes after interruption.

Verify files shows each game file, original backup and stored mod layer; select a row for an explanation.
It never repairs files. Raw hashes/JSON are under Technical details. More → View result reopens the last check for
this session; refreshing clears it. Verify again after changing files or priorities. Health warnings take
precedence over update notices. Search matches names, authors, descriptions and IDs; counts reflect matches.
An interrupted operation is shown as Recovery needed rather than an empty installed-mod list.
Description and Files it changes have separate scrollable tabs. More also holds its update page when available,
leaving Verify/Remove visible without crowding out files at minimum size. Table statuses are short; select a row for details.

For creating mods, character conversion, texture editing and 3D exploration, download
Toy Story 3 Modding Tool separately. No Python is required for either compiled application.
